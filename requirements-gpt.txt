# ChatGPT-style sandbox libraries for the `gpt` image.
# Names only (latest compatible). Torch/torchaudio/torchvision are installed
# separately from the CPU wheel index in the Dockerfile.
#
# Omitted on purpose:
# - OpenAI-internal: artifact_tool_v2, caas_jupyter_tools, detect-installer
# - CUDA: nvidia-nccl-cu12
# - GUI / display: PyAutoGUI and friends, python3-xlib, pyttsx3, playwright
# - Jupyter notebook stack (this runtime is exec(), not a notebook server)
# - pytest / coverage / debugpy
# - APM: datadog, ddtrace, sentry-sdk, opentelemetry-*
# - opencv-python (headless variant is used instead)
# - pip / uv / setuptools (build image already has them)
# - server stack already in requirements-server.txt (fastapi, uvicorn, …)
